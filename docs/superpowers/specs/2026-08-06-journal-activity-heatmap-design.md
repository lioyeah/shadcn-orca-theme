# 日志视图年度块活动热力图设计

> **历史文档：** 该功能已于 2026-08-07 从插件中完整移除，不再由运行时代码或构建产物引用。本文档仅保留设计决策记录。

## 目标

在 Orca 主编辑区的日志/日期视图底部增加一个只读的年度活动热力图。热力图展示最近 365 天每天涉及的块数量，帮助用户快速感知自己的记录密度，同时不改变编辑流程。

## 已确认的产品规则

- 只显示在主编辑区的日志/日期视图，不显示在普通块视图或其他面板。
- 采用全宽底栏布局，固定在主编辑区可视区域底部；热力图与 `.orca-block-editor` 同级，正文在编辑器内独立滚动，底栏始终可见且为正文预留空间。
- 每个格子代表一天，按 GitHub 类似的周列布局排列。
- 覆盖最近 365 天，并标记月份边界。
- 一天内同一个块只计一次。
- “涉及”包括块在当天创建，或当天最后修改。
- 组件没有点击、悬浮提示、跳转或筛选交互。
- 没有活动的日期仍保留空格子；没有可用数据时显示完整但低对比度的空网格。
- 热度使用当前主题的 `--primary` 色阶，并与编辑器背景混合生成五级颜色；浅色和深色主题都自动适配。

## 结构与归属

新增独立的年度热力图模块，负责数据聚合、DOM 生命周期和渲染；主题 CSS 只负责视觉样式，不在 CSS 中伪造统计数据。

模块包含三个职责：

1. **数据收集器**
   - 计算最近 365 天的本地日期边界。
   - 通过 Orca 后端查询创建日期和修改日期落在范围内的块。
   - 对两个查询结果按块 ID 去重，再将每个块归入创建日和修改日对应的日期桶。
   - 对同一块同一天只保留一个计数。
   - 缓存最近一次结果，避免日期切换或主题切换时重复请求。
2. **日志视图挂载器**
   - 只在当前 active 日志面板存在时创建组件；普通块面板与双日志分屏的非 active 侧不挂载。
   - 将组件插入当前面板可见布局层（优先 `.orca-hideable:not(.orca-hideable-hidden)`）中，作为 `.orca-block-editor` 的同级 footer；通过 `shadcn-journal-activity-layout` 标记该布局层为纵向 flex，正文区域 `flex: 1` 可滚动，底栏 `flex: 0` 固定在可视区域底部。
   - 不修改全局 `#main`、所有 `.orca-panel` 或非日志面板的宿主布局。
   - 通过 MutationObserver 处理日志视图切换和编辑器节点重建。
   - 插件卸载时移除组件、布局标记、观察器和未完成请求。
3. **热力图渲染器**
   - 使用语义化容器、月份标签、周列和日期格子。
   - 为每个日期设置 `data-date` 和 `data-count`，但不绑定交互事件。
   - 根据最大日计数计算 0 到 4 的等级；全年度无活动时所有格子为等级 0。

## 数据流

```text
日志视图出现
  → 计算最近 365 天边界
  → 查询 created 与 modified 日期范围
  → 按块 ID 合并并按本地日期聚合
  → 渲染年度格子
  → Orca 状态或日志 DOM 更新
  → 取消旧请求并刷新当前快照
```

后端查询失败时，组件保留上一次成功快照；首次加载失败时显示空网格，不显示错误弹窗，也不阻塞编辑。按用户本地时区将日期归桶，避免 UTC 跨日导致热度落在错误日期。

## 视觉规则

- 热力图作为编辑器背景与正文之间的无边框中间层：使用纯色 `var(--background)`，不增加卡片外框、上边界、focus outline 或 ring。
- 底栏固定在面板可视区域底部，不随正文滚动；正文在 `.orca-block-editor` 内独立滚动，底栏通过 flex 占位为正文预留空间，不覆盖正文末尾。
- 外层上下内边距、月份行与周列间距、格子间距和最小格子尺寸适度放宽，保持 53 周列动态缩放，窄宽度下降低尺寸与间距，不产生横向滚动。
- 标题行与日期范围在常见宽度下完整显示；极窄宽度允许范围换行，不使用单行省略截断完整日期。
- 五级颜色由 `--primary` 与 `--background` 混合生成：
  - 0：背景混合色，接近编辑器背景；
  - 1–4：逐级增加主色比例；
  - 文本、月份和图例使用 `--muted-foreground`。
- 不覆盖宿主编辑器的正文、块句柄、折叠点样式；所有布局覆盖限定在带 `shadcn-journal-activity-layout` 标记的日志面板布局层内。

## 生命周期与边界

- 组件只属于当前日志视图；离开日志视图时立即移除。
- 主题浅色/深色切换只触发颜色重新计算，不重新查询数据。
- 日志日期前后切换不改变热力图的 365 天范围。
- 组件不持有用户数据副本，只保留当前聚合快照和短期缓存。
- 请求竞态通过递增请求序号或 AbortController 处理，旧响应不得覆盖新快照。

## 验证范围

实现后至少验证：

- 日志视图显示，普通块视图不显示；
- 365 天边界、月份标签和周列排列正确；
- 同一块同一天创建并修改时只计一次；
- 创建日期和修改日期分别落入正确日期桶；
- 空数据、查询失败和恢复成功状态不影响编辑；
- 浅色、深色以及窄宽度下没有横向溢出；
- 日志视图重建或切换后不会出现重复组件；
- 插件卸载后组件和观察器均被清理。

## 非目标

- 不提供点击跳转、日期详情、tooltip、筛选或导出功能。
- 不改造 Orca 原生日志数据模型；仅对当前 active 日志面板的可见布局层增加插件标记与 footer 节点。
- 不在普通块视图、查询视图、侧边栏或设置页重复显示。
